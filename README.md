ISLA Eventos

Esta plataforma permite aos utilizadores consultar os eventos disponíveis e futuros do ISLA.

INSTRUÇÕES:


Para correr este programa devem ser colocados os seguintes comandos no terminal:
composer install
cp .env.example .env
php artisan key:generate
php artisan serve

O Composer e o PHP devem estar instalados na máquina que vai executar a plataforma.

Para abrir, basta aceder a https://127.0.0.1:8000 no navegador de preferência.
